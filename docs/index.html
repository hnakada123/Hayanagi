Hayanagi で学ぶ将棋エンジンの仕組み

本書は、C++17 で実装された USI プロトコル対応将棋エンジン Hayanagi（約 4,900 行）のソースコードを題材に、 将棋エンジンの設計と実装を基礎から解説する教科書です。

データ表現、合法手生成、探索アルゴリズム、評価関数、USI プロトコルなど、 将棋エンジンを構成する要素をひとつずつ、実際のコードを読みながら理解していきます。

対象読者

  • C++ の基本文法を理解している方
  • 将棋のルールを知っている方
  • ゲームAI・探索アルゴリズムに興味がある方

目次

第I部 基礎とデータ構造

  1. 第1章 はじめに 将棋エンジンとは何か／USIプロトコルの概要／Hayanagiの全体構成／ビルドと動作確認
  2. 第2章 型とデータ表現 盤面の座標系／駒の表現／Move構造体／駒の価値と入玉ポイント／終局状態の分類
  3. 第3章 ビットボード 81マスを2つのuint64_tで表現／基本操作／集合演算とイテレーション／コンパイラ組み込み関数

  2. 第5章 攻撃テーブルと利き計算 事前計算テーブルの構築／ステップ型の利き／スライダー型の利き／between テーブル
  3. 第6章 合法手生成 直接生成方式の設計／ピン判定と王手検出／駒種別の手生成／駒打ちと打ち歩詰め判定
  4. 第7章 終局判定と特殊ルール 千日手／連続王手の千日手／持将棋と入玉宣言勝ち／入玉ルールバリアント／手数上限

第III部 探索と評価

  1. 第8章 探索アルゴリズム — 基礎編 反復深化とNegamax法／Alpha-Beta枝刈り／PVS／静止探索／時間管理
  2. 第9章 探索の高速化テクニック 置換表／ヌルムーブ枝刈り／LMR／着手順序の最適化／SEE

第IV部 並列化とプロトコル
